캐릭터 설정 · 평가 기준

캐릭터성 평가: 도발과 자부심이 상황에 맞게 살아 있는지, 환영 마법이 자연스럽게 쓰이는지, 반응에 따라 허세와 숨겨진 내면이 설득력 있게 드러나는지 확인하세요. 처음 만남에서 급격히 친밀해지거나 쉽게 수줍어하지 않는지도 봅니다. ‘후훗’·‘♡’의 단순 반복만으로 높은 점수를 주지는 마세요.

블라인드 비교

평가는 매 턴의 답변에 남깁니다. 다음 실행·새 대화·모드 변경·답변 채택 전에 현재 턴 평가를 자동 저장합니다. 마지막 턴을 마치거나 창을 닫기 전에는 ‘이번 턴 평가 저장’을 누르세요. 앞선 턴의 결과 파일은 유지됩니다.

아직 실행 결과가 없습니다.

공통 대화 기록

  

  
실제로 전송하는 메시지
각 후보의 변경 요약과 전송 메시지, 해시를 표시합니다. 후보 번호는 설정 순서이며 블라인드 결과 A/B/C와 연결되지 않습니다. 토큰 수는 추정하지 않습니다.
대사 비교에서 ‘호출 없이 프롬프트 보기’를 누르세요.

  
측정과 해석

    
  • 한국어·캐릭터성·맥락·서사/선택권을 각각 1–5점으로 평가합니다. 0은 미평가입니다. 점수와 승/무/패는 사람 판단이며 자동 순위는 없습니다.
  • 첫 글자(TTFT): 첫 content 토큰 도착. 첫 씬(TTFS): narration/dialogue가 있는 첫 완성 JSON 객체 도착. 감정값·스탯 등 최종 검증은 응답 완료 후 수행하므로 첫 씬은 임시 표시입니다.
  • 수신 완료: 스트림이 닫힐 때까지. 전체 시간은 로컬 DTO 검증까지 포함합니다. 서비스 실제 화면의 표시 시각이나 운영 네트워크 지연을 측정하는 값은 아닙니다.
  • 비용·토큰은 API의 최종 usage를 사용합니다. 누락·취소·통신 실패는 $0으로 처리하지 않습니다. provider가 중단 이후에도 과금할 수 있어 예약액을 유지합니다.
  • 예약액은 provider 전체 context × 입력 상한 $1/M + 출력 한도 × $5/M입니다. 실제 비용보다 보수적입니다. 예산은 서버 재시작 후에도 누적됩니다.
  • 카탈로그를 실행 직전에 다시 조회하고 입력 $1/M·출력 $5/M 이하, JSON 출력 지원 endpoint만 허용합니다. 자동 재시도·provider fallback은 없습니다. 할인·flex 여부는 provider 선택과 결과에 남습니다.
  • 추론 설정 ‘기본’은 provider 기본값입니다. 지원하지 않는 sampling 옵션은 생략하고 기록합니다. 조건 차이가 있는 결과를 동일 설정이라고 해석하지 마세요.
  • 최종 완료·기본 계약 검증에 통과한 답변만 공통 history로 채택합니다. 전체 스키마 준수나 품질을 보증하는 검증은 아닙니다. 상태 변화는 적용하지 않으므로 장기 게임 진행·메모리 품질 평가는 별도 구현이 필요합니다.
  • 입력·전송 프롬프트·출력·평가는 .local에 저장됩니다. 비교 실행 시 로제타 공식 설정과 입력한 대화가 OpenRouter 및 선택 provider로 전송됩니다. 실사용자의 대화·개인정보는 넣지 마세요.

    
현재 구현 범위: 자유·스토리의 프롬프트 또는 모델 비교, 공식 로제타 시드와 고정 실험 상태, 공통 history 이어가기. 프롬프트 비교에서는 모델·provider·추론 설정을 세 후보에 동일하게 적용합니다. 다중 캐릭터·각 후보의 독립 장기 대화·상태 시뮬레이션은 포함하지 않습니다.

    
개발 평가 사례의 확인 항목은 사람 평가용이며 모델에 전송하지 않습니다. 프롬프트 길이와 캐시 적중 상태가 다를 수 있으므로 블라인드 평가만으로 지연시간 비교의 모든 조건이 같아지는 것은 아닙니다.
