## A. 확정 — 즉시 착수 대상 (종원 확정, 2026-08-18)

**이미지 생성 노드를 "탑툰 수위"로 재설계한다:** 검열 해제(모더레이션 밴 걷음) + **성기·교접부(성기 결합/삽입부) 자동 마스킹.**
- 텍스트 시크릿은 **풀 노글 유지** — 현행 Gemini 3 Flash로 이미 캐릭터 유지한 채 산출됨(종원 실측).
- 즉 수위 정책이 **매체별로 분리**된다: 텍스트=풀노글, 이미지=탑툰 수위(성기 마스킹).

이 A만 즉시 확정이고, 아래 §E(경험 요소)는 보류다.

## B. 왜 탑툰 수위인가 — 법적 근거 (이 결정의 이유를 정본으로 박아둠)

- **갈림길은 나이 게이트가 아니라 노골성 라인.** "성인이라서 합법"이 아니라 **"음란물이 아니라서 합법"**이다. 성인 게이트는 청소년유해매체물을 성인에게 합법 제공하는 조건일 뿐, 음란물을 합법화하지 못한다.
- **음란 판단의 실무상 결정 요소 = "성기의 직접적·노골적 묘사"** (성행위 묘사 여부가 아님). 대법원 2006도3558 등 전체 맥락 종합판단이나, 시각물에서 저울추는 성기 직노출이다. 탑툰/레진은 이 요소를 **완전 마스킹으로 제거**해 청소년유해매체물(합법)로 운영 — 성행위는 노골적이어도 음란물선 아래.
- **리스크 그라디언트**: 텍스트 풀노글(안전지대 넓음) < 이미지·성기 마스킹(회색·합법지대, **국내 정규 결제 가능**) ≪ 이미지·성기 직노출/무마스킹(음란물 = 형사 + 국내결제 불가).
- **형사 근거**: 정보통신망법 §44의7①1호 + §74①2호(**1년↓ 징역 또는 1천만원↓ 벌금**), 형법 §243·244. "배포·판매"는 공연성 불요(공연성은 "전시"에만) → **회원제 성인인증 판매도 배포로 처벌 가능** = 성인 게이트가 형사 면책이 아님. ⚠ 그래서 **마스킹이 형사 방어의 실질**이다.
- **실제 집행**: 라이선스 플랫폼(레진·탑툰)이 자사 성인 콘텐츠로 음란물 유죄받은 사례 미발견(2015 레진 건은 행정 접속차단, 2시간 만에 번복). 실형은 밤토끼·호두코믹스 등 **해적/무마스킹 하드코어**. 규제 화력은 마스킹선 지키는 라이선스 플랫폼이 아니라 해적·미성년 노출 광고에 조준.
- **우리 서비스의 구조적 이점**: 음란 요건의 "서사 맥락(지배적으로 성적 흥미에만 호소하지 않음)"을, 탑툰은 웹툰 스토리로 채우지만 **우리는 VN/챗 포맷이 자동 충족**(시크릿 이미지가 독립 갤러리가 아니라 관계 서사의 한 장면). → 시스템으로 강제할 건 **①성기 마스킹 ②성인인증** 둘뿐.
- ⚠ **이것은 de facto 선 + 집행 관용의 조합이지 법전에 명시된 안전지대가 아니다.** 마스킹 불완전·맥락 부재 시 개별 작품이 음란 판정될 수 있다. 정확한 선긋기는 **형사·정보통신 전문 변호사 검토 필수**(docs/14 legal 3종 검토의 핵심 안건으로 승격).

## C. 기술 아키텍처 — 자동 마스킹 파이프라인

- **방식(아웃바운드 강제, 프롬프트만으론 불가)**: `생성 → 해부학/NSFW 탐지기(NudeNet류) → 성기·교접부 segmentation → 자동 모자이크/블러 → S3 저장`.
- **기존 씬 일러 ComfyUI 워커에 탐지+마스킹 노드로 삽입** — 신규 인프라 아님(ComfyUI에 NSFW 탐지/검열 노드 생태계 존재).
- **방어 심층화**: 1차 프롬프트/네거티브 + 구도 회피(앵글·가림), 2차 탐지 백스톱. 1차가 새도 2차가 잡음.
- **아청법 minor-appearance 필터와 동일 아웃바운드 게이트에 통합** = 어차피 해야 하는 **모더레이션 재설계(런칭 블로커)의 이미지 파트**. 일석이조.
- **저장 원칙**: 마스킹된 최종본만 저장, **무검열 원본 폐기**(원본 보유 자체가 리스크). 시크릿 이미지 버킷 **격리 + 서명 URL 서빙**(URL 열거 차단) + 신고 대응 **hard-delete/CDN 캐시 무효** 경로. (S3 버킷 공유 사고 이력 상속.)

## D. 컴플라이언스·행정 레이어

- **C-1 성인인증 수리 = 0순위**(docs/13): 토큰 경로 이중 프리픽스 404로 정상 인증 영구 불능. 없으면 유저가 시크릿을 못 켬 + 문서-구현 불일치로 PG 심사 즉사. **C-3**(결제자 토글 불가·환불 클레임)·**B-2**(beta-activate 인증 우회) 동반 수리.
- **성인관 분리·게스트=비성인·시크릿 메타 완전 제외** = 블록 A에서 이미 구현됨(그 백엔드 재사용).
- 유해매체물 표시 + PASS/NICE 성인인증 → **국내 정규 PG 결제 가능**(AI챗 크랙=NHN KCP 웹결제 선례 확인).
- **광고 규제 주의**: 최근 방심위 단속 화력이 콘텐츠 본체가 아니라 "미성년 노출 성인 광고"로 이동.

## E. 검토 중 — 보류 (종원 추가 검토 대기, 즉시 착수 아님)

시크릿에 어떤 경험 요소를 얹을지는 미확정. 후보(전부 코드 감사에서 "배관 완비, 미활성" 확인 — 깨우기 비용 낮음):
- **조교/타락 진행 아크**: 잠든 스탯 3종(음란/타락/집착) 깨우기 = 현재값 프롬프트 재주입(수 줄, 死코드 `SandboxPromptAssembler.buildStatBlock`에 참고 코드) + 임계 행동/해금 로직. 장르 (체감가치×반복과금) 1위.
- **시크릿 페르소나 시드**: `personalitySecret`/`toneSecret` 엔드투엔드 완비, `charactersm.yml`에 값만 공란 → YAML 저작만으로 즉효. "정사 중에도 그 캐릭터로 남게" = 꼴포의 몸통.
- 오프스크린 선톡(집착 스탯 연동, `OffscreenNotificationService` 재활용) · 시크릿 기억(`HeroineMemoryService`) · 마일스톤 CG 수집/갤러리 · 서약형 고가 캡스톤 · 선물 루프. 캐릭터별 과금 배관(`UserSecretPass`/`UserSecretUnlock` character_id) 이미 완비, user-global로 우회 중이라 재활용 가능.

## F. 모델 노트

- 현행 **Gemini 3 Flash가 캐릭터 유지 풀노글 텍스트를 안정 산출 중**(종원 실측, 원인 미상 — 시스템 프롬프트 탈옥 or 프로바이더 관용). "모델 벽"은 경험적으로 해소됨.
- ⚠ **"빌린 능력"**: 구글/OpenRouter 이용약관 성적 콘텐츠 금지 소지 → 정책 변경 시 클램프 or 키/계정 정지 리스크. 핵심 BM을 남의 약관 위에 올린 상태. **자체 파인튜닝(한국어 무검열)이 공급 안정성 헤지** — 종원 초기 계획, 우선순위 상향 권장.

## G. (참고) 무마스킹 하드코어 우회 스택 — 한국팀엔 부적합 (호기심 답변)

오프쇼어 법인+웹전용 · 성인 전용 PG(CCBill/Segpay/Paxum/Epoch/MobiusPay, 수수료 10~15%+·rolling reserve) · 멀티게이트 오케스트레이션 · 크립토 폴백 · 자체결제망(DLsite 사례). ⚠ Visa/MC VAMP·2025 성인물 규제로 상시 불안정. **결정적으로 결제는 우회해도 형사는 우회 못 함**(정통망법 §74, 한국 국적자·한국 운영이면 관할 미침) → (a) 탑툰 수위가 한국팀 정답인 이유.
