## 적용과 무결성

운영 관측은 전체 캐릭터 26행. 목표 9행은 모두 `source=OFFICIAL`. 연화·시크릿·UGC 등 나머지 17행은 보존한다. canonical `application-characters.yml`의 외형 필드 9개도 같은 값으로 변경해 이후 시더가 옛 mock 값을 재적재하지 않도록 한다.

원본 태그와 행별 나머지 컬럼 해시는 Git 제외 로컬 `tools/tts/.local/appearance-before.json`에 보존한다. 트랜잭션은 원본 26행 비교, 공식 목표 9개 비교, 변경 9개, 미대상 17개, 나머지 컬럼 26개 해시 불변을 모두 확인한다. 짧은 테이블 쓰기 잠금으로 확인과 UPDATE 사이 변경을 막고, 5초 잠금/15초 SQL 타임아웃을 둔다. 불일치는 예외와 롤백으로 처리한다. 검토 전 운영 적용하지 않는다.

COMMIT 전 검증 실패는 원자적으로 롤백한다. COMMIT 응답 유실/연결 오류는 롤백으로 단정하지 않는다. 실행기는 별도 읽기로 현재 상태를 관측하고, 확인되지 않은 작업을 자동 재적용하지 않는다. 성공 기록도 COMMIT 응답과 독립 읽기 대조가 끝난 뒤에만 남긴다.
