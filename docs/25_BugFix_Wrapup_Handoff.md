### 🟠 2단계 — G-6 미드나잇 스탯 300/100

**한 커밋으로.** 서버가 위변조 검증에 같은 값을 쓰므로 한쪽만 바꾸면 정상 유저가 거부된다.

- 같은 파일 주석 3곳(`:76 :80 :91`)과 프론트 주석(`:127 :134`)이 아직 **40/20**이다 — 함께 정정

**검증**: 프리미엄 구독으로 방 생성 → 300 초과 배분이 거부되는지 · 3축 만렙 시 지배 스탯이 그 축으로 잡히는지.

## 4. 검증 규율 (이 세션에 적용)

1. **완료는 grep으로 판정한다** — 도구 반환값이 아니라 최종 파일 상태
2. **가드를 넣었으면 가드 문자열 개수를 센다**
3. **배치마다 새 컨텍스트의 적대적 검토** — 그리고 **회귀를 고치려고 새 장치를 넣었으면 그 장치도 검토에 건다**
4. **픽스 커밋마다 `19_assets/rejudgment_delta.md` 해당 행을 같은 커밋에서 갱신** — 행이 없으면 만든다
5. **종원 답을 받으면 `decisions_confirmed.md`에 먼저 적고** 파생 문서를 갱신
6. **인용은 원문 문장으로** — 기호만 쓰지 않는다
7. 프론트: `npm run check:tdz` → `npm run build`. **빌드 통과는 검증이 아니다**(렌더해야 터지는 오류가 있다)
8. 백엔드: `./gradlew compileJava test --tests '*Test'`. 새 빈·설정을 만들었으면 **실기동 확인**
9. enum에 값을 추가하면 **DB CHECK 제약도 함께 넓힌다**(§2-7)
