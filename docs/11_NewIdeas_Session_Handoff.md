## D. 인프라 사건 기록 (이번 세션 해결)

- **Flyway V18 체크섬 불일치**: 적용된 마이그레이션 파일을 리뷰픽스로 수정한 실수 → checksum UPDATE로 repair. 교훈: 적용된 마이그레이션은 수정 금지, 새 버전으로.
- **씬 엔드포인트 CUDA**: `cuda>=12.6` vs 구드라이버 호스트 복권 → Allowed CUDA Versions 12.6+ 필터로 해결.
- **UGC 워커 0.3.0 crash-loop**: 22.7GB 이미지 콜드 풀 + Container Disk 부족(에러 로그 없는 start/remove 반복이 지문) → 디스크 40GB+CUDA 필터+풀 완주 대기로 해결. **장기 과제: 모델을 Network Volume으로 분리해 이미지 ~3GB화**(리빌드마다 콜드 풀 비용 제거 — docs/09 백로그 합류).
- RunPod 크리덴셜은 `.idea/workspace.xml` 런 설정에 있음(PoC 러너 직접 실행 시 env로 주입).
