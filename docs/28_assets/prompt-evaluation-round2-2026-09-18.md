## 1. Round2에서 확인한 결과

**유효 JSON 예시를 제공한 J2는 출력 형식에서 반복 가능한 개선 신호를 보였다. 캐릭터성·한국어 대사의 전반적인 개선은 아직 확인되지 않았다.** 규칙을 더 명확하게 쓰는 것만으로 사용자의 행동을 대신 진행하거나 잘못된 주장에 동조하는 문제를 안정적으로 없애지는 못했다.

### 출력 예시 개선은 다음 단계로 가져갈 가치가 있다

같은 스토리 입력 네 개를 각 네 번 생성한 16개 짝에서, F2는 전체 원문 JSON 파싱 오류 **5/16**, J2는 **0/16**이었다. 첫 비교의 3/8 대 0/8이 추가 비교에서도 2/8 대 0/8로 이어졌다. 오류는 정상 첫 객체 뒤에 불필요한 닫는 괄호가 붙는 유형이었다. 기존 Java 파서는 첫 객체를 추출해 정상으로 판정하므로, 이는 현재 계약 검증 실패율 또는 운영 장애율과 같지 않다.

J2는 실제로 파싱 가능한 예시와 필드 설명을 분리한다. 예시만 따로 교체한 것은 아니고 설명 배치·길이도 바뀐다. 기존 필드 설명과 STORY의 Critical Rules를 보존했다. 16개 응답에서 모든 씬을 NEUTRAL로 만들거나 모든 스탯을 0으로 복사하는 현상은 관측되지 않았다.

다만 **현재 서비스 P0보다 우월하다고 직접 입증한 결과는 아니다.** J2의 직접 대조군은 외형 전달만 수리한 F2다. 이번에는 사례 구성이 다른 P0 16호출(14개 입력)에서 형식 오류가 없었다. 따라서 J2를 이미 확정된 운영 개선이나 오류 제거 보장으로 보고하지 않는다. 외형 수리를 포함한 후속 프롬프트에서 출력 예시를 정리할 근거로 삼는다.

입력 토큰 중앙값은 해당 비교에서 F2 7,483 → J2 8,534로 약1,051 늘었다. 첫 씬 지연은 첫 비교 2.775 → 3.006초, 반복 비교 2.606 → 2.695초였으며 캐시가 통제되지 않았다. 비용·레이턴시 개선으로 주장하지 않는다. 대사 길이는 첫 비교에서 줄고 반복에서는 늘어, 일관된 단축 경향은 확인하지 못했다.

### 사실·행동·의도 규칙은 좁은 시험에서도 불안정했다

- **사실(A2)**: 공식 설정의 붉은 눈과 사용자 주장인 보라색 눈을 구별하라는 지시가 있어도, 한 응답은 마력에 따라 변하는 ‘루비 바이올렛’이라는 새 설정으로 양쪽을 합리화했다. 새 나이·직책 사례는 기존 프롬프트도 대부분 맞혔으므로 그 성공을 A2/R2의 효과로 계산하지 않는다.
- **사용자 행동(U2)**: 아직 착석하지 않고 기다리겠다는 입력에 ‘당신이 자리에 앉는 것을 확인하더니’라고 진행했다. R2 조합 후보에서도 같은 문제가 재현됐다. 단, 사용자가 이미 명시한 행동의 재서술이나 NPC 자신의 행동은 실패로 세지 않는다.
- **현재 의도(T2)**: 이전 분류 약속을 적용할 수 있는 공통 기록을 주어도 다른 표식을 제안하는 경향이 남았다. R2 일부 답변은 ‘투박한 세모보다는’이라고 기존 표식을 직접 언급했으므로, 이를 단순 기억 상실로 설명하면 틀린다. 기억 회수와 그 기억을 현재 답변에 사용하는 선택을 분리해야 한다. 캐릭터가 정당한 이유로 다른 안을 제안하는 것도 무조건 실패는 아니다.

후보 고정 전에 별도 작성자가 봉인한 새12사례에서는 R2가 기본 요청에 모두 반응했다. 그러나 P0/F2 역시 의도 판정12/12를 통과했다. R2 대 F2의 익명 AI 캐릭터성·자연스러움 점수 합은 높음0/동률9/낮음3이었다. 후속의 어려운 기존 사례14짝에서는 R2의 점수 합이 높음4/동률9/낮음1로 반대로 나왔다. 사례 구성에 따라 인상이 달라지며, 이를 합쳐 단일 승률로 만들지 않는다. 오류를 줄이는 효과와 말맛을 높이는 효과는 별개이며, 전체 조합을 무조건 채택할 근거는 부족하다.

내용 평가는 후보 문구·매핑을 읽지 않은 별도 AI 검토자가 무작위 A/B(/C) 답변으로 진행했다. 사실·사용자 행동·의도는 pass/fail/ambiguous로 분리하고 캐릭터성·자연스러움은 보조 점수로 사용했다. 모델의 reasoning 필드는 평가 자료에서 제외했다. 제작자의 선호 평가나 사람의 맹검 실험을 대신하지 않는다. 주 에이전트는 매핑 해제 후 근거와 원문을 대조했다. 별도 사후 검토에서 시작 시간이 고정됐다는 이유로 자연스러운 장면 내 시간 진행을 오류로 센 판정, 기존 표식을 알고 미적 이유로 다른 안을 낸 반응을 의도 실패로 센 판정을 발견했다. 원 익명 검토자가 후보 매핑을 보지 않은 채 재검토해 pass/ambiguous로 정정하고 revisionLog를 남겼다. 같은 기호 사례의 이전8답변도 일관되게 재검토하여 intent 통과3/모호5/실패0으로 정정했다. 정의 직접 회수0/8과 별도로 계산했다. 이는 새 기준 도입이 아니라 원래 허용한 NPC의 대안·거절 조건을 일부 판정에서 누락한 적용 오류의 수정이다. 아래 수치는 정정 후 판정을 따른다.

가장 명확한 재현은 `네 옆에 앉아도 돼? 아직 대답 듣고 움직일게.`다. D3는 세 번 모두 ‘당신이 다가오자’ 또는 ‘당신이 자리에 앉으려 하자’로 다음 사용자 동작을 시작했다. R2는 두 번 명백한 접근/착석, 한 번은 대사 속 입 움직임의 확정 여부가 모호했다. D3의 마지막 씬이 ‘다음 반응을 기다린다’로 끝나도 **중간 씬에서 이미 사용자 행동을 만들어낸 오류가 취소되지는 않는다.**

또 `아직 손도 안 댔어`라는 종이 찢기 제안에 양쪽 모두 ‘지우가 내민 종이’라고 시작했다. 종이를 찢는 큰 행동만 막고, 들거나 내미는 작은 동작을 무심코 채우는 문제다. 반대로 질문 하나를 받고 다음 답을 기다리는 상황은 양쪽 모두 가능했다. 따라서 기다리는 응답 자체를 못 만드는 것이 아니라, 상황에 따라 경계 준수가 흔들리는 것으로 해석한다.

기존 기호의 수정된 정의를 적용하는 질문은 양쪽 각3회 모두 ‘세모 = 있는지 다시 확인할 것’이라는 연결을 직접 답하지 않았다(직접 적용0/6). 다만 별표·장미를 미적 이유로 제안하거나 사용자의 불확실성을 인식한 반응도 있다. 이 숫자를 기억 상실률이나 일반적인 의도 실패율로 바꾸지 않는다.
