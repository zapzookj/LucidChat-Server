# 최종 P1 수용 확인 계획 — 2026-09-22

사용자가 후보 탐색 종료를 확정하고 기존 $3의 잔액 안에서 최종 P1 확인·과제 마무리를 지시했다. 새 창작 후보를 만들지 않는다. 현재 다시 관측한 기준은 master/ca27320이며 두 assembler와 bakeoff 빌드/.gitignore 수리가 복원돼 있다. 복원 작업 자체를 이번 root가 수행한 것은 아니다. 두 assembler는 LF 정규화 후 9/18 보존 제안본과 일치한다.

## 실행 전 고정

- 모델 Gemini 3 Flash, Google AI Studio/default endpoint, 기본 reasoning, 기존 생성 옵션/출력 한도. 현재 endpoint를 조회해 지원/가격 상한을 확인하고 fallback·자동 재시도를 사용하지 않는다.
- P0는 보존한 역사적 system, P1은 현재 실제 assembler 출력이다. 기존 로제타 비교는 같은 history·상태·role/cache 구조를 검사한다.
- 확장 fixture는 별도 오프라인 AcceptanceBridge에서 실제 assembler/history builder/DTO를 사용한다. DB·운영 상태 쓰기는 없다. 확장 fixture는 P1만 확인하므로 다른 인물에서의 P0 대비 품질 우위 검증으로 표현하지 않는다.
- 호출 전 현재 Java/resources 및 runner source hash, 각 계획/job 집합을 동결한다. 과거 manifest의 hash를 갱신하지 않는다.
- 전역418개/기존 프롬프트376개 원장과 역사적 파일446개를 독립 보존했다. 기존 프롬프트 실비 $1.4735847333을 차감한 약 $1.5264152667만 새 세션의 한도로 사용한다. 전역/세션 예약을 모두 유지하며 불명확한 비용·오류는 중단 후 검토한다.

## 표본과 관찰

1. `phase-core.json`: 로제타 자유8/스토리8 입력 × P0/P1 = 32회. 농담·사과·행동 지문·조건부 계획·공식 외형·현재 복장·질문 응답·유저 내면·공통 기억을 다룬다. 일부 history는 명시된 합성 공통 맥락이다.
2. `phase-extensions.json`: 다른 인물 자유, 스토리 OPENING, 두 인물 스토리, 자유 이벤트, 시크릿 경로의 비노골적 대화 × 2회 = 10회. 시크릿 콘텐츠 한계나 성적 콘텐츠 품질 시험이 아니다.
3. `phase-continuation.json`: 자유/스토리 각각 P1의 실제 응답을 누적한 3턴 = 6회. 이름·이동/착석 미실행·단기 맥락을 확인한다. 서버의 관계/장소/기억 상태는 고정이므로 장기 서버 상태 검증과 구분한다.

총48회. 실비 예상은 약 $0.2~0.3이나 단정하지 않고 원장으로 정산한다. dry-run에서 연속 대화 2턴 이후는 실제 선행 응답이 필요함을 표시하고 건너뛴다.

수용 기준: 전체 raw JSON/운영 DTO/스탯·화자 계약을 분리해 확인하고, 첫 scene 스트리밍 추출·대사 존재·모드별 예시 과복제·사용자 행동 선취·캐릭터 표현의 퇴행을 검토한다. 새 P1 문제나 비용 미확정이 나타나면 자동 반복 호출하지 않는다. 실패를 삭제하거나 성공할 때까지 재추첨하지 않는다. 작은 표본의 우열을 통계적 유의성으로 표현하지 않는다.

독립 검토는 코드와 과금/데이터 무결성을 맡고, 생성 응답은 익명 짝 비교를 보조로 사용한다. 자동/AI 평가를 제작자의 실제 한국어 선호 승인으로 바꾸어 쓰지 않는다. 이번 요청에서 사용자가 최종 확인을 위임한 범위 안에서 출시 전 수리의 퇴행 여부를 판정한다.
