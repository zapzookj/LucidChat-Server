# 최종 보고서·공개 응답 독립 검토

검토일: 2026-09-22. 검토자: 별도 컨텍스트 `experiment_audit`. 대상은 상위 최종 보고서와 `statistics.json`, `contract-audit.json`, `responses.json/html`, 연결된 검증 기록이다. 추가 유료 호출·소스·원장 수정은 하지 않았다.

**판정: 마감을 막는 수치 오류나 중요한 범위 과장은 발견하지 않았다.** 수리 전 64회와 이벤트 수리 후 4회를 구분하고, 원래 실패를 남기며, 자유 모드 지연 증가·오프닝 사용자 감각 대필·표본과 상태 고정의 한계를 명시한 결론은 증거에 부합한다.

확인한 내용:

- 공개 JSON의 44개 상황 묶음에 응답 68개가 중복·누락 없이 들어 있다. HTML에 포함한 JSON과 공개 JSON은 동일했다. 각 응답의 세션·소스 hash·입력·후보·상태·비용·TTFS·씬과 앞선 대화 이력을 보존된 원문과 대조했다. 모델 reasoning을 응답/이력에 노출하지 않는 것도 확인했다.
- 전체·단계별·후보별·핵심 모드별 호출 수, 비용, TTFS/총시간·입력/출력/캐시 토큰 중앙값, 검증 실패·엄격 JSON 실패 수를 원본 기록으로 재계산해 일치시켰다. 68회 비용 $0.2375572833, 누적 444회/$1.7111420167, 잔액 $1.2888579833은 독립 과금 감사와 일치한다.
- 대사 없는 응답은 68개 중 0개다. P1 44개 중 36개는 0이 아닌 스탯을 포함하며, 나머지는 이벤트 6개의 의도된 0스탯과 오프닝 2개의 빈 스탯이다. 통계의 구조 중앙값은 엄격 JSON 65개만 사용한다는 제한을 명시하며, 전체 68개 판정은 계약 대조 자료에서 확인할 수 있다.
- 자유 핵심과 재확인 합계 16쌍 중 15쌍에서 P1의 첫 완성 씬이 늦었다. 재확인 P1의 긴 TTFS는 25,851ms와 13,481ms로 본문과 맞는다. 속도 최적화나 콜드 캐시 비용 절감으로 주장하지 않는 해석이 적절하다.
- P0의 엄격 JSON 실패 3개와 P1의 이벤트 의미 계약 실패 1개를 운영 DTO 파싱 실패로 혼동하지 않는다. 원래 이벤트 2회와 최종 소스의 이벤트 4회를 합쳐 수리 효과로 설명하지 않는다. 핵심 16쌍의 AI 평가 수치와 쌍별 판정 자료도 일치한다.
- Java 31건·Node 107건 등 실행 수치는 연결된 `final-verification.json`과 일치한다. 이번 문서 검토에서 빌드·테스트를 재실행하지는 않았다. `local-server-check.json`은 최종 소스의 양 모드 HTTP 무료 조립, 원장 불변, 유료 0회를 기록하며 브라우저 렌더링이나 모델 추론 검증으로 확장하지 않는다.

검토 중 바로잡은 사항:

1. `phase-core/F07-r1-t1-P0`의 원문 첫 JSON 객체에는 캐릭터 속마음이 있지만, 엄격 JSON 실패 시 씬만 복구하던 열람 exporter가 이를 빠뜨렸다. root가 첫 JSON 객체를 먼저 복구하도록 수정했고, 재생성 후 68개 전체에서 속마음 누락이 0임을 독립 확인했다. 이 응답의 엄격 JSON 실패 표시는 유지했다.
2. 통계에 남아 있던 `/undefined/` 축의 중복 분류 7개는 유효한 분석 축이 아니므로 정리를 권고했다. root가 이 불필요한 분류를 제거하고 재생성했다고 보고했다. 본문의 수치나 판단에는 영향이 없다.

별도 과금·원본 보존 근거는 [independent-billing-audit.json](independent-billing-audit.json)에 있다. 이 문서 검토는 제작자 취향 평가, 실제 DB/FE 통합, 장기 기억, 운영 지연 분포, 네 번 재현 이후의 이벤트 무오류를 입증하지 않는다.
