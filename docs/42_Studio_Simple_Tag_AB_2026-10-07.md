# UGC 원화 태그 지시 단순화 A/B

관측·기록일 2026-10-07. 출처: 사용자 “단순한 이미지 태그 지시+컨셉만 / 현행 지시의 이미지 태그만 단순화” 실제 샘플 비교 요청. 유료 LLM 2콜·RunPod 8요청을 실행했다. 운영 애플리케이션·DB·과금·엔드포인트 설정 변경과 배포는 없다. 사용자 설정 UGC 최소/최대 worker 1/1을 보존했다.

## 실험 조건

색감 문제를 신고한 실제 job26의 입력 컨셉 1종을 양 조건에 동일하게 사용했다. 요청 이름은 없고 현재 캐릭터 나이 21세인 아이돌 연습생 설정이다. 전체 입력/구조화 산출·비밀 값·provider 원래 ID는 Git 제외 로컬에 보존했다.

- **A:** WAI Illustrious용 일러스트 아트디렉터, 일본 서브컬처풍의 예쁘고 매력적인 2D 캐릭터, 컨셉 개성·완성도 우선, 태그 수 자유. 외형·복장/표정·분위기/배경·구도·조명의 세 배열과 JSON 출력 계약만 요청했다. 추가 인격 생성·조명/구도 금지·태그 개수 강제는 없다.
- **B:** 배포 JAR에서 추출한 현행 SYSTEM_PROMPT의 그림체/appearance/persona/scene 지시만 A의 간결한 방향으로 교체했다. mood/bg_color/character/base_pose/moderation/전체 스키마는 유지했다. 두 조건의 user 메시지 바이트는 같다.
- LLM 양 조건 `openai/gpt-5.6-sol`, temperature0.7, max_tokens8192, json_object, 비스트리밍 각 1콜. 응답도 같은 model/OpenAI provider로 기록됐다. seed는 이미지 seed이며 LLM 산출 seed가 아니다.
- **주 비교 raw_tags:** 산출된 세 태그 배열을 순서대로 positive에 그대로 조인, negative 빈 값. 서버 quality/gender/style 프리픽스와 명시 스타일 필터를 사용하지 않았다.
- **보조 current_assembly:** 같은 산출에 현행 quality/gender/`anime illustration, 2d, cel shading` 프리픽스, 명시 스타일 필터와 현행 negative를 적용했다. 제외 태그는 모든 슬롯 0개였다.
- 2 LLM 조건 × 2 서버 조립 조건 × 서로 다른 2 seed = 최종 원화 **8장**. sampler/detailer seed쌍은 `(2026100701,2026110701)`, `(2026100702,2026110702)`이며 각각 네 조건에 동일 적용했다.
- 실제 배포 WF1 WAI checkpoint/detail LoRA0.6/clip1, 1024²/batch1/euler/simple/30step/CFG4, FaceDetailer20step/CFG4/denoise0.4/wildcard빈값 유지. 기존 VAE 출력에 SaveImage만 하나 추가해 **후처리 전 8파일**도 저장했다. 추가 이미지 추론은 없다.

이때 “raw_tags”는 서버 추가 태그가 없는 조건이고 “FaceDetailer 전”은 워크플로 단계다. 두 개념을 구별한다. 산출 태그의 머리색·의상·구도가 A/B 간 다르므로 고정 얼굴 일치보다 컨셉/완성도/그림체를 비교한다. 서버 조립의 효과는 각 A/B 내부에서 태그·seed가 동일한 쌍으로 비교한다.

## 실제 결과

| 조건 | 외형/표정/씬 태그 | 태그 그대로 결과 | 현행 서버 조립 결과 |
|---|---:|---|---|
| A 단독 이미지 요청 | 20/8/11=39 | 연습실·거울·아래쪽 카메라, 자신감/놀리는 인상. 피부와 실내가 자연스러운 색. 배경·옷·신발의 입체광택이 꽤 남음 | 같은 태그/seed에서도 청록·초록·노랑, 넓은 검은 음영, 강한 색 분할이 두 seed에 반복됨 |
| B 통합 요청, 이미지 지시만 단순화 | 19/8/8=35 | 회색 단순 배경·카우보이 구도. 얼굴선/표정의 2D 인상과 자연 피부색. 옷·신발 광택, 프롬프트에 없는 신발 소품은 남음 | 같은 태그/seed에서도 청록·파랑·강한 검은 음영이 두 seed에 반복됨 |

**이번 두 산출의 색감 회귀는 태그 요청 단순화만으로 해결되지 않았다. 현행 서버 조립을 적용한 4/4에서 이상 발색이 재현되고, 동일 태그의 추가 강제 없는 4/4는 자연색이다.** 새 산출에는 colored/neon/purple lighting 태그가 없으며 rim/studio lighting은 양 조립 조건에 동일하게 남았다.

후처리 전 이미지에도 같은 발색 차이가 이미 존재한다. FaceDetailer 전후 변경 픽셀 비율은 1.50–4.52%, RGB 평균 절대 변화는 0–255 단위0.22–0.75였다. FaceDetailer가 이 샘플의 전체 색조를 처음 만든 공정이라고 볼 증거는 없다. 얼굴을 정리하면서 표정이 조금 바뀌는 차이는 별도로 관측됐다.

후처리 전 전체 이미지 HSV 평균 채도는 A seed1 `0.211→0.572`, A seed2 `0.302→0.689`, B seed1 `0.143→0.418`, B seed2 `0.067→0.434`(태그그대로→현행조립)다. 피부 전용 지표·품질 점수·제품 게이트로 쓰지 않고, 눈에 보이는 전체 색감 변화의 보조 관측으로만 기록한다.

**A의 단독 지시가 B보다 보편적으로 우수하다는 결과는 아니다.** A는 장면/구도를 더 만들고 B는 서브컬처 얼굴과 스탠딩에 가까운 구도가 나왔지만, 태그 산출은 각각 한 번뿐이다. 태그 개수 강제를 없앤 두 조건은 이전 55–88개 요구보다 짧아졌다. 자연 색감과 목표 2D 그림체는 별개의 평가 축이며, 자연색 조건에도 반입체 광택이 남는다.

## 판단과 다음 변경 후보

LLM이 직접 밝은 조명을 추가한 것만으로 이번 색감을 설명할 수 없다. 서버의 스타일/negative 조립을 우선 수정 대상으로 삼을 근거가 생겼다. 최근 패치의 `cel shading` 공통강제와 추가3D negative가 유력하지만, 이번은 quality/gender/style/negative 묶음을 함께 비교했으므로 특정 태그 하나의 인과효과라고 단정하지 않는다. 명시 스타일 필터는 제외0개여서 이번 8장에서 실제 태그 삭제 효과가 없었다.

현 단계에서는 **이미지 태그 지시 단순화는 유효 후보로 유지하고, 이전 스타일강제/추가negative를 먼저 분리 비교하거나 되돌린 뒤 새원화로 검증**하는 것이 합리적이다. 서비스에 B형 통합 구조를 유지할지, A형 이미지 요청을 별도 분리할지는 이번 1종·1산출만으로 확정하지 않는다. 두 작업은 프로필-외형 정합성·추가콜 비용/지연도 함께 판단해야 한다. 이번 요청은 실험이므로 제품 수정을 실행하지 않았다.

## 2026-10-07 사용자 시각 평가

출처: 사용자가 비교 페이지를 확인한 뒤 “솔직히 내가 눈으로 그냥 보고 판단했을때는 1-A가 가장 좋아보인다.”라고 평가했다. **① 추가 강제 없음 / A 이미지 태그 요청만** 조건을 이번 개선의 품질 레퍼런스로 기록한다. 특정 seed만을 최종 파라미터로 채택한 것으로 해석하지 않는다.

입체광택이 남는다는 기술 관측을 이 샘플의 불합격 기준으로 삼지 않는다. 이번 사용자 평가에서는 캐릭터의 전체적인 매력·구도·자연색을 포함한 완성도가 우선이다. 태그 단독 요청의 보편적 우열·특정 강제 태그의 인과효과가 입증됐다는 의미는 아니다.

구현 방향 제안은 A의 간결한 이미지 전용 지시+컨셉으로 태그를 만들고, 원화에는 해당 태그를 그대로 전달하는 것이다. 1-A를 재현하려면 스타일강제만 일부 제거하는 방식과 구별해, 실험에서 비워 둔 negative 및 미주입 품질/성별 프리픽스까지 함께 고려해야 한다. 기존 WAI/LoRA/샘플러/FaceDetailer는 실험에서도 유지됐다. 프로필 생성은 이미지 태그와 분리하되, 프로필의 외형/복장 서술에 같은 태그를 참조시켜 정합성을 확보하는 것이 후속 설계 후보다. 이번 답변은 시각적 선호이며 구현·배포 완료나 세부 적용 방식의 확정으로 기록하지 않는다.
