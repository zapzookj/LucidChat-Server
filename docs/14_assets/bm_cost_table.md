## 6. 결론 — 위험 지점 vs 여유 지점

### 🔴 위험 (마진 음수/박함 — 가격 확정 전 반드시 결정)

1. **구독자 부스트가 최대 폭탄.** LUCID_PASS 14,900원/월 = "부스트 무제한"인데 구독자는 기본 E(V1 1E/V2 2E)만 차감 + 리젠 에너지는 매출 0. V2 부스트 턴당 원가 ₩77~219 → **월 1,000턴 헤비유저 1명이 원가 ₩7.7만~21.9만** — 구독가의 5~15배. 구독 부스트에 일일 캡(예: 부스트 50턴/일) 또는 부스트만 flash-thinking급으로 다운그레이드 검토 필수.
2. **UGC 캐릭터 20E는 원가 ≒ 판매가.** E당 원가 44~55원 vs 매출 39.6~50원 — T3 구매자 기준 **확정 적자**, 실수취 기준이면 전 티어 적자. 최소 **30E 이상**으로 인상하거나, 감정 14종→8~10종 축소·Qwen 콜 절감(원가의 60%+가 감정 스테이지)이 필요. 단계 차감 구조라 중도 이탈 시 손실은 제한적인 점은 방어 요소.
3. **V1 보수 케이스(긴 대화+출력 캡 도달)는 1E로 breakeven 근처(−2%@T3).** V1 캐시 브레이크포인트가 사실상 미부착(`history.size()==3||%20==0` 조건)이라 절감 기회를 흘리고 있음 — V2처럼 매턴 부착으로 바꾸면 전형 기준 E당 5원 절감.
4. **UGC 월드 보수 케이스 적자 가능(−15%@T3).** 원가 지배 요인이 이미지가 아니라 **W0의 gpt-5.6-sol 출력 단가($30/M)** — W0만 flash로 내리면 총원가가 절반 이하로 떨어져 안전권.
5. **씬 일러는 웜일 때만 안전.** flex 콜드(8분+ 실측) 히트 시 1장 원가가 5E 매출을 초과. 상시 웜 워커는 월 $550~800 고정비 — 초기 트래픽에선 배보다 배꼽. 콜드 구간 대기 UX + flex 유지가 현실적.

### ✅ 여유 (현행가 유지 가능)

- **V2 STORY 2E (핵심 소비처): 마진 31~83%** — 보수 케이스도 흑자. 안전.
- **V1 SANDBOX 전형: 마진 62~79%.**
- **씬 일러 5E (웜 기준): 마진 77~88%** — E를 낮출 여지도 있음(프로모션 카드).
- **비구독 부스트(5E/10E): 마진 18~85%** — 5배 차감 설계가 잘 방어함.
- **UGC 감정 리롤 2E·월드 리롤 1E: 마진 ~50%+** — 리롤 유도 프로모션 여지.

### 참고 감가 요인
- 표 마진은 VAT 포함 총액 기준 — **실수취 기준 마진은 일괄 −12~13%p**.
- 리젠(무료) 에너지로 소비되는 턴은 매출 0 — 실효 블렌디드 마진은 구매:리젠 소비 비율에 비례해 추가 하락.
- LLM 토큰 규모·이미지 렌더 시간은 [추정] — OpenRouter Activity 대시보드/RunPod·fal 청구서로 1주 실측 대조 권장.
