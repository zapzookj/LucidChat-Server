## 1. 페르소나 렌즈 5축 — 축별 정밀 정의 (블록 B의 심장)

**대원칙**: 스탯은 유저의 능력치가 아니라 **"캐릭터가 유저를 어떻게 인식하는가"**다. 프롬프트 서술자는 반드시 "당신(캐릭터)은 {user}를 ~하게 인식한다" 형태로 쓰며, 효과는 **1턴 안에 대사·태도로 드러나야 한다**(은근한 내부 판정 금지 — 그게 기각된 구 문법이다). 축별 구간(예: 0-2/3-5/6-8/9-10) 서술자 템플릿을 만들 것.

| 축 | 캐릭터의 인식 | 높음(8~10)의 관찰 신호 | 낮음(0~2)의 관찰 신호 — 페널티가 아니라 별도의 재미 |
|---|---|---|---|
| **매력** | 끌린다 | 시선 의식·두근거림, 외모 언급, "…왜 자꾸 시선이 가지" | 외모에 무심 — 순수하게 내면 위주 상호작용 |
| **친근함** | 편하다 | 격식 붕괴, 금방 말 놓음, TMI·투정·흐트러진 모습 무방비 노출 | 서먹한 손님 대접 — 말 고르기, 어색한 침묵, '초반 감성' 거리감 |
| **신뢰감** | 믿음직하다 | 비밀·고민을 먼저 털어놓음("이 얘긴 너한테만"), 부탁을 의심 없이 수락 | 의심·떠보기 — "그 말, 진심이야?" 시험하는 밀당 역학 |
| **카리스마** | 어렵다/우러러본다 | 존댓말 전환·말 고름·긴장, 중요한 일에 조언을 구함 | **만만하게 봄** — 별명, 놀림 1순위, 잔심부름 (인기 포지션) |
| **신비** | 궁금하다 | 질문 세례("대체 무슨 생각 해?"), 알아내려 먼저 다가옴 | 열린 책 취급 — "지금 그 말 하려 했지? 다 보여" 독심 놀이 우위 |

**구현 주의 3가지**:
1. **카리스마·친근함은 '반말'이라는 같은 신호를 공유**한다 — 서술자에서 반드시 분리: 공손함/긴장의 축=카리스마, 스스럼없음/무방비의 축=친근함. (카리스마 낮음의 반말=만만함, 친근함 높음의 반말=편안함 — 뉘앙스가 다르다.)
2. 긴장쌍이 설계 의도다: 친근함↔카리스마↔신비가 자연 트레이드오프 — StatAllocator 총점 배분에서 "다 높게"가 불가능해야 빌드 선택이 서사가 된다.
3. 낙선 후보 13종(관능·도도·순수·유쾌·든든함·유능·귀여움·명성·다정 등, 축별 높/낮 효과 정의 포함)은 **프리미엄 렌즈 팩 1호 재료** — 상세는 세션 트랜스크립트의 후보 풀 표 참조(관능=시크릿 시너지 최강 후보).

**극장 무변경 원칙**: 극장 아바타 5축(매력/재치/대담/지성/공감 — 행동 생성기)은 TheaterState 소속으로 완전 별개. 페르소나 개편이 극장 코드를 한 줄도 건드리면 안 된다. 이유: 극장은 아바타가 '행동'하는 감상형이라 행동 생성 스탯이 맞고, 자유/스토리는 유저가 직접 타이핑하므로 행동 스탯이 설 자리가 없다(렌즈 전환의 근본 이유).

## 2. 프로필 중심 플로우 + 나이 게이트 (블록 B)

- **개념 역전**: 기존 "카드 라이브러리에서 골라 쓰기" → **"항상 존재하는 단일 활성 프로필 + 카드는 저장 슬롯"**(게임 세이브 문법). 프로필 모달 필드: 이름/나이/성별/소개(자유 서술)/렌즈 5축 배분. "현재 프로필을 카드로 저장" / "카드 불러오기"가 카드의 전부다.
- **방 생성**: 피커 UI 없이 현재 프로필 자동 적용 + "시작 전 프로필 편집" 진입점 하나. V1 생성 4곳도 같은 방식(그래서 배선이 가벼워진 것). 방 생성 시 스냅샷·중도 교체 불가는 현행 유지.
- **나이 게이트 — 의도를 정확히**: 프로필에서 나이는 자유 입력이다(미성년 유저의 SFW 이용은 정당한 케이스 — 프로필 단계 차단은 과잉으로 기각됨). 하드 게이트는 **시크릿 활성 시점 단 한 곳**: 나이<19면 활성 불가. UX는 부드럽게("시크릿 모드는 성인 페르소나로만 이용할 수 있어요 — 나이를 수정할까요?" 모달), 로직은 하드하게(수정 없이 우회 불가). **이중 방어**: 시크릿 방 프롬프트 주입 시에도 나이<19면 차단. "제안만 하고 통과"는 절대 금지 — UGC 미성년 게이트와 같은 급의 절대선.
- 스키마: UserPersona에 age 컬럼(V25) + 렌즈 축 재정의. 기존 카드(구 5축 값)의 마이그레이션 정책은 구현 시 종원과 결정(추천: 구 카드 스탯은 리셋하고 본문만 보존).

## 3. 게스트 브라우징 (블록 A)

- **탐색은 전부 공개**: 캐릭터 피드·프로필·월드 카드·UGC 탐색. **행동은 전부 게이트**: 대화 시작·스튜디오·보관함·결제·에너지 조회.
- **딥링크 복원이 핵심 UX**: 게스트가 캐릭터 X의 프로필에서 "대화 시작" 클릭 → 로그인 모달("이 인연과 대화하려면 로그인이 필요해요") → OAuth 완료 → **X와의 방 생성으로 직행**. 이 복원이 온보딩을 대체한다(캐릭터를 이미 골랐으므로 '첫 만남' 화면 스킵). '첫 만남' 온보딩은 아무것도 안 고르고 가입한 빈손 신규(방 0개)에게만.
- **보안 3원칙**: ①비로그인=비성인 취급 — 시크릿 관련 메타(플래그·상품·수위 태그)는 게스트 응답에서 필드 자체를 제외 ②게스트 DTO는 별도 스코프(프롬프트류 내부 필드 재검증) ③비인증 IP 레이트리밋(스크래핑 방어).
- 공개 전환 대상 엔드포인트는 permitAll 추가 시 하나씩 게스트 응답을 검수할 것 — 일괄 개방 금지.

## 4. BM 구현 세부 (블록 C)

- **부스트 치환**: openai.pro-model → `google/gemini-3.6-flash`. **전제 3개가 원가 성립 조건**이므로 같은 커밋에서: ①V1 프롬프트 캐시 `cache_control`을 V2처럼 매턴 부착(현행 3번째·20배수 조건 제거 — ChatStreamService:1385 부근) ②부스트 턴 max_tokens 캡 하향(보수 케이스 원가 초과의 원인이 캡 풀도달 — V2 8192→6144 수준에서 시작해 품질 확인) ③thinking 모델이므로 reasoning 억제(OpenRouter reasoning effort low/off — 부스트 요청에만). 근거 수치: docs/14_assets/bm_boost_and_bench.md.
- **UGC 25E**: application.yml `ugc.energy` 단계값을 6/5/11/3으로(시작 6 불변이 의도 — 진입 문턱 유지, 몰입 후 회수). StageCosts DTO·프론트 배지가 서버 단일 소스라 자동 추종하는지 확인.
- **페르소나 슬롯**: `hasFreePersonaUnlock()` placeholder(무조건 true)를 실정책으로: 자유 입력·스탯=무료, 슬롯 무료 3/구독 10.
- 백로그(별도 A/B 후): 기본 모델 3.5-flash-lite 치환, UGC 월드 W0 flash 치환 — **품질 검증 없이 치환 금지**(stage0 모델 품질이 외형 태그를 좌우한 전례).

## 5. 레거시 처분 구현 노트 (블록 D)

- 게이트 플래그는 기존 관례(`${ENV:default}` yml 노브) 따를 것. 엔딩·업적은 "게이트 오프=코드 보존"이 의도 — 삭제는 §G의 🔴 목록만.
- **V1 STORY 트랙 제거 시**: 잔존 V1 STORY 방 데이터 처리를 먼저 결정(마이그레이션 vs 읽기 전용) — 방을 고아로 만들지 말 것.
- **승급 시험 제거 시**: V2 RelationPromotionService 패턴(자격 활성+LLM 발동)을 SANDBOX에 이식하는 것까지가 한 세트다. 시험만 뽑고 승급 자체를 죽이면 안 된다. 승급 세리머니(Relationship Up 연출)는 유지.
- **복장 해금 오프 시**: 씬 outfit 필드·복장 표시·전환은 살아있는 기능이다(리플레이 영속에도 사용) — 죽이는 건 '관계 단계별 LOCK'뿐.
- beta-activate는 프론트 트리거+백엔드 엔드포인트 **세트 제거**(프론트만 지우면 API 착취면이 남는다).

## 6. 이미 배포된 것의 수용 트레이드오프 (재작업 금지 목록)

- 씬당 1회 심의 '전송 시작' 발제: 턴 실패 시 409 안내→availability 재조회 자가치유(무과금) — **의도된 수용**, ChatPage/V2 주석 참조. '새 로그 확정' 시점 해제로 바꾸지 말 것(init 레이스가 더 위험해서 기각된 안).
- 리플레이 중 씬 일러 무대 언마운트: 의도된 설계(씬 재현이 주인공, 일러 점프는 마커 썸네일 전담).
- V2 scenesJson 씬 컨텍스트 4필드 사문(SceneResponse null 하드코딩): 알려진 상태 — V2 스레딩은 별도 백로그(docs/13 #12).
