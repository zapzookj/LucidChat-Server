## 검토 필요 논점 (전문가 확인 요청 사항)

1. **CI 해시 저장의 적법성**: 연계정보(CI)는 주민등록번호 대체수단으로 처리 제한이 엄격함. 본인확인기관이 아닌 사업자가 CI(해시 형태 포함)를 저장·이용하는 것의 법적 근거와 허용 범위 — **최우선 확인 필요**.
2. **국외 이전의 법적 근거**: 대화 내용의 LLM 제공사 전송이 "정보통신서비스 제공에 관한 계약 이행을 위해 필요한 처리위탁·보관"으로 고지만으로 가능한지, 별도 국외 이전 동의가 필요한지. 동의 필요 시 가입 플로우의 동의 항목 설계.
3. **대화 로그의 성격**: 대화 내용에 민감정보(성적 지향 등)가 포함될 수 있는 서비스 특성상, 민감정보 처리에 준하는 별도 동의·보호 조치가 필요한지.
4. **기기 핑거프린트 수집의 근거**: 동의 없이 정당한 이익(부정 이용 방지)으로 수집 가능한지, 수집 동의 항목에 포함해야 하는지. FingerprintJS 상용 클라우드 사용 시 국외 이전 이슈.
5. **AI 학습 활용**: 대화 로그를 모델 학습에 활용하기로 결정하는 경우 필요한 동의 방식(별도 선택 동의, 옵트아웃), 가명처리 요건.
6. **법정 보존 기간 수치 확인**: 본문에 기재한 5년/5년/3년/3개월이 현행 법령과 일치하는지 확인.
7. **수집 항목의 실제 부합 여부**: 코드·인프라 기준으로 실제 수집 항목(OAuth로 받는 필드, NICE 응답 필드, 로그 항목)과 본 방침 기재 항목의 일치 여부 대조.
8. **탈퇴 후 부정 이용 방지 목적 보유**(핑거프린트, CI 해시)의 허용 기간.
