4. 진입 플로우 · 게스트 게이트 (P4)

  • 캐릭터 카드 → 프로필 → 대화 시작 유지 (종원 OK 판정). 프로필 오버레이는 기존 CharacterProfileView 재사용, 스타일만 토큰 정합.
  • 스토리·극장은 추상 명사로 먼저 제시하지 않음 — 월드 카드 안의 두 행동 버튼이 각각 1줄 설명을 달고 나옴. 홈의 '스토리 세계관' 섹션이 스토리 탭의 예고편.
  • 게스트 게이트 규칙(단일 선언): 탐색은 전부 열림(홈·스토리·프로필), 행동 시점에만 로그인 시트(기존 GuestLoginGate 재사용). 버튼에 자물쇠·비활성 표시를 하지 않는다 — 탐색을 위축시키지 않기 위해. 규칙 안내는 게스트 배너 한 곳에서만.
  • 게스트에게 멤버 상태(진행 중 표시·'이어하기' 라벨)는 렌더하지 않음 — 스토리 카드 버튼은 게스트에게 항상 '이야기 시작하기'.
  • 보관함·스튜디오 탭은 게스트 클릭 시 로그인 시트(화면 진입 없음 — 업적 API도 인증 필수).
  • 온보딩: 빈손 신규만 첫 만남(2단계). 게스트 딥링크 복원이 온보딩 대체(기존 postLogin 로직 보존).

6. 구현 계약 (시맨틱 · 상태 · 유틸)

  • 모든 카드·행은 button 또는 href 있는 a — div+tabindex 금지. 내비 활성 탭은 aria-current="page", 보관함 세그먼트는 tablist/tab/tabpanel + aria-selected.
  • 포커스 토큰: :focus-visible → box-shadow 0 0 0 2px rgba(167,139,250,.55) 전역 1규칙. disabled는 opacity .4 + hover 무효(:not(:disabled) 가드).
  • 조사 유틸 필수: 동적 캐릭터명 + 와/과 — 한글 종성 판별 (code-0xAC00)%28>0 → '과', 아니면 '와'. 비한글 종결 닉네임은 이름 생략형 폴백("이 캐릭터와 대화 시작하기").
  • 텍스트 오버플로: 캐릭터명·월드명 1줄 ellipsis, 태그라인 1줄 ellipsis, 월드 설명 2줄 clamp, 레일 크레딧 닉네임 max-width ellipsis.
  • 카드 아트는 3:4 단일 비율(온보딩 포함) — 썸네일 제작·크롭 기준 통일. 썸네일 부재 시 그라데이션+이니셜 폴백(이 목업의 플레이스홀더가 곧 폴백 디자인).
  • 월드 카드 버튼 행은 flex column + margin-top:auto로 하단 고정 — 설명 길이와 무관하게 정렬 유지.
  • 스켈레톤 3골격(카드형/월드형/리스트형)·빈 상태·에러·부분 실패 규칙은 '상태' 화면의 매트릭스를 정본으로.

7. 이 목업이 실물과 다른 점

  • 캐릭터 아트는 그라데이션 플레이스홀더 — 실서비스는 3:4 썸네일. 단 썸네일이 없어도 성립하는 카드가 설계 목표(플레이스홀더 = 폴백 디자인).
  • 프로필 오버레이·스튜디오 내부·설정·로그인 시트는 기존 컴포넌트 재사용이라 목업 생략(스타일 토큰 정합만 적용).
  • 구현은 기존 스택 그대로: Tailwind 토큰화 + framer-motion 절제 사용, 게스트 API·딥링크 복원 재사용.
